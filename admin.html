물건 등록

법원경매정보 검색 결과를 붙여넣으면 사이트 목록에 올릴 물건을 자동으로 골라 드립니다. 자동으로 법원 사이트를 조회하지 않습니다.

1. 법원 사이트에서 복사하기

  1. 법원경매정보 → 경매물건 → 물건상세검색
  2. 법원 선택(서울·경기·인천 법원을 하나씩), 용도 건물 → 주거용건물 → 아파트, 검색
  3. 결과 아래 페이지당 40으로 늘리고, 화면에서 Ctrl+A → Ctrl+C
  4. 아래 칸에 Ctrl+V. 여러 법원 결과를 이어서 붙여넣어도 됩니다.

2. 올릴 물건 고르기

수도권 아파트, 매각기일 6일 이상 남음, 유찰 0~2회, 위험 표시 없음을 자동으로 체크했습니다. 관심 등록이 많은 순서입니다.
